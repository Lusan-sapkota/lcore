# Lcore

## Git commits
- Commit small and often: one logical change per commit, never one big batch.
- Message is one short sentence in plain English, e.g. "Fix rate limiter cleanup crashing under load."
- Tests and docs for a change go in the same commit as the change, or in a small follow-up.
- Work on the current release branch (e.g. `v0.0.6`), not `main`.
