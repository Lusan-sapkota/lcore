# Pyodide (self-hosted)

Pyodide 314.0.8 (MPL-2.0, https://pyodide.org), core runtime only, used by the tutorial playground.
`lcore.py` here is a copy of the repo's `lcore.py`, refreshed by `python3 docs/build.py`.
To update Pyodide, replace pyodide.js, pyodide.asm.mjs, pyodide.asm.wasm, python_stdlib.zip and pyodide-lock.json from the same release.
